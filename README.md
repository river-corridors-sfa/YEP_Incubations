# Data and scripts associated with "Immediate biogeochemical responses of sediment rewetting are not impacted by pyrogenic organic matter inputs"

Vanessa A. Garayburu-Caruso1*, Robert E. Danczak1, Viviana Freire Zapata1, Xia Gillespie1, Alyssa Radakovich1, Lupita Renteria1, James C. Stegen1,2, Nicholas Ward3,4, Jianqiu Zheng5,6, Allison N. Myers-Pigg3,6*

To be submitted to ES&T Letters.

## Summary

NOTE: The manuscript associated with this data package is in preparation for submission to ES&T Letters. The data, scripts, figures, and tables may be revised based on reviewer feedback. Upon manuscript acceptance, this data package will be updated with the final dataset and additional metadata.

This data package is associated with the manuscript "Immediate biogeochemical responses of sediment rewetting are not impacted by pyrogenic organic matter inputs" (Garayburu-Caruso et al., in preparation). The package contains analysis-ready data products and scripts used to evaluate immediate aerobic respiration, dissolved oxygen dynamics, geochemistry, and FTICR-MS molecular composition responses following sediment rewetting with and without pyrogenic organic matter inputs. The analyses focus on variably inundated stream sediments and compare dry versus wet sediment histories, treatment effects, fitted oxygen consumption parameters, and molecular composition patterns used in the manuscript figures and Table 1.

Underlying data are archived through ESS-DIVE as the Pyrogenic Organic Matter Laboratory Experiment data package (Gillespie et al., 2025). For details on how to navigate data packages generated by this project, see https://data.ess-dive.lbl.gov/portals/PNNLRiverCorridorSFA/About.

At the top level, the repository is organized into the following main folders:

1. `v2_data`: Analysis input data and metadata from the ESS-DIVE data package, including respiration, dissolved oxygen, geochemistry, FTICR-MS, field metadata, and associated data dictionaries.
2. `modeling_outputs`: Derived model outputs used for fitted oxygen consumption parameters and downstream summary tables and figures.
3. `Figures`: Static figure files and statistical outputs associated with the manuscript figures.
4. `Tables`: Summary tables and manuscript-ready table outputs.
5. `src`: Active R scripts used to generate Figure 1, Figure 2, Figure 3, and Table 1.
6. `Archive` and `Archive_2`: Archived exploratory scripts, older data products, and previous analysis versions that are retained for provenance but are not part of the active manuscript workflow.

The active `src` folder contains:

1. `Plot_fitted_Vmax_kL_DryWet_Wilcox.R`: Generates Figure 1 outputs comparing fitted oxygen consumption parameters between dry and wet sediments.
2. `Figure2_FTICR_NMDS_inundation_history_panels.R`: Generates Figure 2 FTICR-MS presence/absence NMDS outputs by inundation history.
3. `Plot_fitted_Vmax_kL_Treatment_KW_Dunn.R`: Generates Figure 3 outputs comparing fitted oxygen consumption parameters across treatments and reporting Kruskal-Wallis and Dunn post hoc results.
4. `Table_1.R`: Generates Table 1 summary statistics and manuscript-ready table outputs.
