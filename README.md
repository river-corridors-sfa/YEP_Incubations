# Data and scripts associated with "Immediate biogeochemical responses of sediment rewetting are not impacted by pyrogenic organic matter inputs"

Vanessa A. Garayburu-Caruso*, Robert E. Danczak, Viviana Freire Zapata, Xia Gillespie, Alyssa Radakovich, Lupita Renteria, James C. Stegen, Nicholas Ward, Jianqiu Zheng, Allison N. Myers-Pigg*

To be submitted to ES&T Letters.

## Summary

This data package is associated with the manuscript "Immediate biogeochemical responses of sediment rewetting are not impacted by pyrogenic organic matter inputs" (Garayburu-Caruso et al., in preparation). The package contains analysis-ready data products and scripts used to evaluate immediate biotic and abiotic rates, dissolved oxygen dynamics, geochemistry, and FTICR-MS molecular composition responses following sediment rewetting with and without pyrogenic organic matter inputs. The analyses focus on variably inundated stream sediments and compare dry versus wet sediment histories, treatment effects, fitted oxygen consumption parameters, and molecular composition patterns used in the manuscript figures and Table S1.

Underlying data are archived through ESS-DIVE as the Pyrogenic Organic Matter Laboratory Experiment data package (Gillespie et al., 2025). For details on how to navigate data packages generated by this project, see https://data.ess-dive.lbl.gov/portals/PNNLRiverCorridorSFA/About.

At the top level, the repository is organized into the following main folders:

1. `v2_data`: Analysis input data and metadata from the ESS-DIVE data package, including respiration, dissolved oxygen, geochemistry, FTICR-MS, field metadata, and associated data dictionaries.
2. `modeling_outputs`: Derived model outputs used for fitted oxygen consumption parameters and downstream summary tables and figures.
3. `Figures`: Static figure files and statistical outputs associated with the manuscript figures.
4. `Tables`: Summary tables and manuscript-ready table outputs.
5. `src`: Active R scripts used to generate Modeling Outputs, Figure 1, Figure 2, Figure 3, and Table 1.


The active `src` folder contains:

1. `Plot_fitted_Vmax_kL_DryWet_Wilcox.R`: Generates Figure 1 outputs comparing fitted oxygen consumption parameters between dry and wet sediments.
2. `Plot_fitted_Vmax_kL_Treatment_KW_Dunn.R`: Generates Figure 2 outputs comparing fitted oxygen consumption parameters across treatments and reporting Kruskal-Wallis and Dunn post hoc results.
3. `FTICR_NMDS_inundation_history_panels.R`: Generates Figure 3 FTICR-MS presence/absence NMDS outputs by inundation history.
4. `Table_S1.R`: Generates Table S1 summary statistics and manuscript-ready table outputs.
5. `Model_DO_biotic_abiotic_v2.R`: Generates modeling outputs.
